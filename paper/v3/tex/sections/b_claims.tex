\section{Claims and evidence}\label{app:claims}

Table~\ref{tab:claims} lists the claims behind the numbers in the paper, each with its source (a script, a data file or a record), a tier, a strength and the hedge it carries. % none
Rows without a prefix are the v2 map of 2026-10-13 (sources T, M, Y, S, E and B name its evidence notes); rows marked V3 come from the evidence dossier of 2026-10-21 and from rows added while writing this version (V3-W). Where a later row updates a v2 row, the v2 row says so. The table is a dated ledger: a row records what we knew when it was written, so a later row supersedes an earlier one (for example, the interleaved yield test that v2 rows list as not run is V3-W36, and round A's outcome is V3-W45, which replaces the mid-run rows V3-G10 to V3-G16). Section and appendix numbers in the v2 group titles are v2's.
Our records call a development run a replica, and the ceiling of Sec.~\ref{sec:curve} a plateau; this table keeps the records' words.
Every number in the body carries the ids of its rows in a source comment, and \texttt{paper/v3/analysis/build\_claims\_appendix.py -{}-check} lists any id cited without a row.

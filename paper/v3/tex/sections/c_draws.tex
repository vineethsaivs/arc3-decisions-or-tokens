\paragraph{Groups.}
The seven live draws before the yield change average 29.25 (SD 1.58). % G2
The eight live draws of the yield family to 2026-10-20 average 34.28 (SD 4.25); the exact one-sided permutation $p$ against the earlier seven is 18/6,435 = 0.0028 (Mann-Whitney $U$ 50.5 of 56). % V3-B5
That is a rank test across different, time-ordered configurations: it ranks the stack and attributes nothing. % V3-B5
The shipped configuration's three draws average 38.43 (SD 3.67) and the variant's four valid draws 31.15 (SD 1.70); the three are the top three of the seven (exact one-sided $p = 1/35$; Welch $t$ 3.19). % V3-B4
We formed the hypothesis that the shipped configuration draws higher on 2026-10-19 from two draws against four ($p = 1/15$); the one draw since, 40.98, sits above all four of the variant's, which has probability 1/5 under no difference. % V3-B4
The five keepalive draws after it, play-identical to the shipped configuration, average 35.04, between the two, so the gap has shrunk as chance and calendar predict; the adapter's three average 37.22. % V3-W16
The variant changes only the draft model's vocabulary, which should leave the output distribution unchanged (speculative sampling preserves it when the verify path is correct), so we do not attribute the gap to it; calendar or node variation plus chance is the economical reading. The same calendar term applies to every time-ordered comparison in the paper. % V3-B4
